Add your event photos here.

Create one folder per event, named:
  YYYY-MM-DD-Event-Name

Example:
  photos/2026-07-15-Summer-Launch-Party/photo1.jpg
  photos/2026-07-15-Summer-Launch-Party/photo2.jpg
  photos/2026-08-02-Team-Offsite/img_001.jpg

The date prefix is optional but recommended — it controls sort order and
is shown under the event title. Supported formats: .jpg .jpeg .png .webp .gif
